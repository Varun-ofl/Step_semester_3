15. A - An interface specifies operations and contracts that a type promises to provide, rather than defining ordinary per-object state or one required implementation.

17. C - DataProcessor must implement both serialize() and reset() to satisfy the contracts of both interfaces.
18. C - An interface is the appropriate construct for a common protocol shared by unrelated classes without requiring shared state or a class implementation.
19. B - Dog IS-A Animal through generalization, while Eagle CAN-DO Flyable through interface realization.
20. A - equals(), hashCode(), and toString() are commonly inherited from the root Object type and are frequently overridden for class-specific behavior.
